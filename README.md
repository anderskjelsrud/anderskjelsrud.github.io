# Anders Kjelsrud — research homepage

Website: https://anderskjelsrud.github.io

## Content

- `index.md`: biography and contact information.
- `research.md`: working papers, publications, replication papers, and dissertation.
- `data.md`: dataset catalogue and existing replication resources.
- `writing.md`: reports and public writing.
- `_layouts/default.html`: shared navigation, including the CV link.
- `assets/style.css`: appearance and mobile layout.

Edit a Markdown file on GitHub with its pencil button, then commit the change to `main`. GitHub Pages will publish the update automatically.

Publication information and external links were migrated from the existing homepage on 10 September 2026. Publication statuses have been retained from that source. The CV is included at `assets/anders-kjelsrud-cv.pdf`. Paper files remain at their existing external locations. The portrait could not be downloaded and is not included. Add the original image when it is available.

## Add a dataset

Add an entry in `data.md` with the name, description, coverage, version, release date, file formats and sizes, documentation, citation and licence. Link to an existing research repository or an uploaded GitHub Release asset. Do not put a file larger than 100 MiB into ordinary repository files. For independent dataset pages, create another Markdown file with the same front matter as `data.md` and link to its `.html` address.

## Publish these files

Upload the contents of this folder to the root of the existing `anderskjelsrud.github.io` repository, including the `_layouts` and `assets` folders. Replace the old `index.md` and `_config.yml`. Keep Pages set to `main` and `/ (root)`.
